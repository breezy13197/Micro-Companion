# Microbiology Companion

Use /docs/companion-architecture.md as the reference for how to build a new companion, naming conventions and shared files.

When generating questions from the provided lectures, make sure they adhere to the Question Writing Guidelines, found in /docs/. Each end of module quiz, and mastery exam should include an adaptive exam where the student can answer targeted questions on the subjects they struggled with.

Use American English localization, ex: color, not colour

## SubModule Activities

The lecture supplies the content; the companion should supply the practice, prediction, visualization, feedback, and integration that are difficult to accomplish during a live lecture.

In addition to the checkpoint questions, each submodule should include some sort of interactive activity. The sub modules should be more than just repackaged versions of the lecture material. Types of interactive materials include (feel free to suggest others not found on this list):

* Drag and drop
* Matching Fill
* Fill in the blank
* Predict → Interact → Explain
* Interactive molecular designs
* Put the pathway steps in the correct order
* Interactive Visual elements where students manipulate a variable and see the effect in real time
Check and ensure that there are a variety of different types of activities across modules and companions.
Use the images from my PowerPoint as a starting point for these images

Reference the 'start here' page from Bacteria1.html and use that as design inspiration for all future companions.
